`cmd/math-verify` 运行有偿基础游戏循环及每次产生的 free spin。其目的是在发布证据获批前捕获
不安全的定义。它不调优轴权重、不选择目标 RTP，也不替代独立实验室的精确数学与 RNG 评估。

## 失败即拒绝的调用

两个 RTP 边界都是必填的十进制比率。例如 `0.96` 表示 96%。边界必须来自获批的游戏/配置规格，
而非模拟结果。

```bash
cd server
go run ./cmd/math-verify \
  -paid-spins 1000000 \
  -bet-minor 1000 \
  -seed 8242832684730926184 \
  -rtp-min "${CERTIFIED_RTP_MIN}" \
  -rtp-max "${CERTIFIED_RTP_MAX}" \
  > math-report.json
```

退出状态：

- `0`：精确的观测赔付/投注比落在闭区间内；
- `1`：已产出报告，但观测 RTP 落在区间外；
- `2`：参数、配置、模拟、理论敞口计算或报告输出失败。

省略任一边界都是错误。RTP 拒绝时 JSON 报告仍会在进程退出前写入，因此 CI 可把失败证据保留为
制品。CI 必须在每个非零状态上失败发布作业。

仓库保留的 `DemoConfig()` 仅是确定性测试夹具，不会由正式 RGS 启动路径选择。当前 v6 夹具定义
`demo-2026-07-29.5` 在种子 `8242832684730926184`、投注 100 最小单位下确定性运行 100,000 次
有偿旋转及其产生的 6,361 次免费旋转，得到总投注 `10,000,000`、实际总支付 `59,903,260` 与
RTP `5.99032600`（约 599.03%）。这个结果使用仅供诊断的宽区间 `[0,100]` 重放得出；该区间不是
发布接受标准，其“通过”状态没有认证或上线含义。夹具刻意不适合正常的低于 1 的接受策略，也不
是抓取配置声明 96% 的数学。正式定义必须独立生成报告并通过获批闭区间；禁止为了让任一定义通过
而放宽区间。

## 可复现身份

每个 v2 报告记录：

- `schemaVersion`；
- `engineRulesSchemaVersion`；
- 游戏与定义版本；
- `configurationSha256`，由精确校验的游戏定义计算；
- 确定性模拟 RNG 算法版本与完整种子；
- 有偿/免费/总旋转计数与配置的投注；
- 用于计算 RTP 的精确赔付与投注总额；以及
- 闭接受区间及其通过/失败结果。

模拟 RNG 为 `splitmix64-rejection-v1`。它仅是确定性证据，绝不用于可赔付的生产结果。规则评
估或 RNG 到结果映射的变更需要新的 engine-rules schema 版本、新的定义哈希/审批与新的黄金/模
拟证据。当前重放的 `engineRulesSchemaVersion` 为
`slots-game-ways3-features-win-cap-paid-facts-v6`，夹具 `configurationSha256` 为
`27565a87d2ef0510ef70969bb3035f5de61d292109fe4254a13903e843b8b1b1`；这两个身份都只对应上述
DemoConfig 工程证据，不能代替本地生产定义或获批商业定义的报告。

## 最大获胜字段

`observedMaximum` 仅包含本模拟流中遇到的最大值。它绝不能作为理论最大值呈现。

`theoreticalMaximumUpperBound` 在模拟前用版本化方法
`authoritative-win-cap-upper-bound-v2` 计算。该方法要求定义携带有效的整场
`maxWinMultiplier`，并以该权威上限约束基础局及其完整 Free Spin 周期的最终责任；缺失、非法或
计算溢出都会使命令失败。它不是通过枚举隐藏商业概率或轴条带推导出的精确数学最大值。
上述 DemoConfig 与本地定义 `local-production-2026-08-26.3` 的该值均为 2500。本次投注 100 的
DemoConfig 诊断报告因此返回基础局与完整 Free Spin 周期责任上界各 `250,000`；本地定义仍须以其
自身身份另行生成报告。溢出会使命令失败，而非回绕或静默省略敞口。

该上界对责任告警与发现缺失的最大获胜控制有用。认证仍需要精确的结果/特性状态证明，包括最大
获胜语义与概率。

## CI 策略

使用若干独立评审的种子与足够的、满足获批置信要求的有偿循环。把每份报告与源提交、编译器/工
具链、依赖锁、可执行文件或镜像摘要、定义审批与实验室证据一起归档。一次 Monte Carlo 通过本
身不能授权数学变更；RTP 失败始终阻断发布。
