# Primal Rampage 三端页面拓扑

## 外层视口

- 浏览器视口负责黑色背景、裁剪和居中。
- PC 内层表面固定为 1280×720，并按原版 1200×900 authored composition 等比铺设；16:10/4:3 PC 对称裁掉渲染器左右翼，使底栏贴住物理底边。手机与平板以 844 逻辑长边和当前真实宽高比连续生成设计表面。
- 所有通道只接受一次等比例 `scale(...)`；移动常规比例完整贴合视口，超出 9:22～22:9 的极端比例才以黑边收口。
- 所有 Pixi、DOM、菜单和输入层都位于同一内层表面；黑边不接收游戏交互。

## 固定层级

1. 城市场景背景与模式调色层。
2. Kong/King 角色层与模式特效层。
3. Jackpot 塔、卷轴框和 NORMAL/ADD 符号层。
4. Logo、Spin、工具栏和 Balance/Bet/Win 状态层。
5. 帮助/玩法遮罩层。

## PC

- Jackpot 五档纵向固定在卷轴左侧。
- 卷轴与角色居中；Logo 位于 Jackpot 上方；Spin 位于右下。
- 状态栏占视口底部 16px，顶部另有 1px 深色纹理接缝；Balance/Bet 在左，Win 在右。
- 帮助页为固定左侧三页签加右侧单轴滚动区；PAYTABLE 使用 750px authored surface，GAME RULES 使用原版白色文档卡。

## 手机

- 任意竖屏尺寸按实际宽高比连续求解，内容规则使用 `pt`：Jackpot 置顶、主场景居中、控制区与状态区位于底部。
- 横屏使用 `ls`：Jackpot/工具分置两侧；紧凑手机横屏仅在 X 轴按原版实机证据展开 1.12 倍，状态区保持移动端紧凑高度。
- 竖屏帮助页使用顶部页签；横屏切换为原版左侧竖向导航，内容单轴滚动。PAYTABLE 内部仍保持同一 750px authored surface，不重排符号卡。

## 平板

- 任意平板竖屏使用 `iPad_pt` 内容规则，保持独立 minBounds，不按手机截图尺寸等比例放大。
- 横屏按官方 `ls` 路由并以平板视口重新计算，不复用手机截图尺寸常量。
- 竖屏帮助页采用顶部页签；横屏采用左侧竖向导航，内容可滚动且按钮可触达。
